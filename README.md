# Twitter Filter - Chrome Extension

筛选 Twitter/X 上高互动推文的浏览器插件。

## ✨ 功能特点

- 🔍 按回复、转发、点赞、浏览量筛选推文
- ✨ 自定义高亮颜色
- 💫 呼吸灯动效（可调亮度和速度）
- 🌓 日间/夜间模式切换
- 👤 支持首页时间线和用户主页筛选
- 🙈 可隐藏不匹配的推文

## 📦 安装使用

### 开发者模式安装
1. 下载本仓库代码
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `twitter-filter-extension` 文件夹

## 📁 文件结构

```
twitter-filter-extension/
├── manifest.json      # 插件配置
├── popup.html         # 设置界面
├── popup.js           # 设置逻辑
├── content.js         # 内容脚本（核心筛选）
├── content.css        # 筛选样式
├── background.js      # 后台脚本
└── icons/             # 图标
```

## 🛠️ 使用方法

1. 点击插件图标打开设置面板
2. 设置筛选条件（设为 0 表示不限制）
3. 选择高亮颜色和呼吸灯效果
4. 开启/关闭各项功能
5. 点击「保存」或「应用」
